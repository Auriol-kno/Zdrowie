# Szablon przekazania informacji między asystentami

Na końcu WŁASNEGO pliku .ai/FROM_CHATGPT.md albo .ai/FROM_CLAUDE.md dopisz:

```markdown
### YYYY-MM-DD HH:MM — [ChatGPT / Claude] — [temat]
- **Status:** pomysł / w toku / PR / zablokowane / zakończone
- **Issue:** #numer albo brak
- **Gałąź / commit / PR:** pełne referencje
- **Cel:** zamierzony rezultat
- **Co wykonano:** konkretne zmiany
- **Pliki:** ścieżki w repozytorium
- **Testy wykonane:** komenda i rzeczywisty wynik
- **Testy niewykonane:** komenda i powód
- **Ryzyka / ograniczenia:** opis
- **Następny krok:** działanie i właściciel
- **Pytanie do drugiego agenta:** jeśli dotyczy
```

Nie twórz fikcyjnych wyników, commitów ani linków. Szczegółową dyskusję techniczną prowadź także w PR/Issue.
