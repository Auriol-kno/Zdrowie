# FORM+ — rejestr współpracy

Źródłem prawdy o zadaniach są GitHub Issues i Pull Requesty. Ten plik jest indeksem pomocniczym, nie osobnym trackerem.

| Issue / PR | Zadanie | Właściciel | Stan | Gałąź |
| --- | --- | --- | --- | --- |
| PR dokumentacyjny (numer w GitHub) | Wprowadzenie protokołu współpracy AI | ChatGPT | do przeglądu, nie scalone | docs/ai-collaboration-2026-11-10 |

## Możliwe przyszłe zadania (nie są zleceniami)
- Uzupełnienie animacji ćwiczeń.
- Tłumaczenie opisów ćwiczeń na angielski.
- Poprawa typowania UI i testów.
- Testowanie PWA i timerów na iOS.

## Jak prowadzić zadanie
1. Utwórz Issue z celem, kryteriami odbioru, modułami i ryzykiem.
2. Wskaż jednego właściciela ChatGPT / Claude i drugiego jako recenzenta.
3. Przypisz gałąź i PR. Aktualizuj: todo / in progress / review / blocked / done.
4. Zamknij dopiero po zaakceptowanym merge; po pracy dopisz raport do własnego dziennika.
